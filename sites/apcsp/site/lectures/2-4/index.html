Using Programs with Data

Use Python to turn CSV records into checkable information through cleaning, filtering, transforming, aggregating, and communicating results.

← Back to the Big Idea 2 handouts

Success criteria

  • Read a CSV file with Python and check field and type assumptions.
  • Complete at least one cleaning, filtering, transforming, aggregating, and visualization step.
  • Explain how output answers a question rather than merely displaying a number.
  • Submit a data insight that includes scope and a limitation.

Five program actions

ActionPython approachContent-metadata example
cleanstrip(), lower(), conversion Tech → tech; reject n/a
transformsplit(), calculated valueSplit tags; calculate engagement.
filterif or a list comprehensionKeep posts tagged python.
combineDictionaries, counters, averagesCalculate count and average views by category.
visualizeTable or text bar chartCompare category average views.

Minimal Python example

tags = [tag.strip().lower() for tag in row["tags"].split("|")]
engagement = (row["likes"] + row["comments"]) / row["views"]
python_rows = [row for row in rows if "python" in row["tags_list"]]

Practice task

  1. Use the unclean CSV to find blanks, capitalization differences, n/a, and duplicate IDs.
  2. Calculate record count, average views, and average engagement by category.
  3. Count posts tagged python and find the length of the longest title.
  4. Create a text bar chart, then write “finding + numeric evidence + limitation.”
Synthetic-data boundary: this data is not Mingcheng Community data. Even a real aggregate should use minimum necessary, de-identified fields and should not display groups with fewer than three records.

Exit ticket

Identify one cleaning line, one filtering line, and one aggregation line in your code. What limitation must still be explained after you create a chart?
