Binary Numbers

Computers represent data with bits; people interpret that representation as numbers, text, images, and sound.

← Back to the Big Idea 2 handouts

Success criteria

  • Explain bits, bytes, and binary place value.
  • Convert positive integers between decimal and binary and compare binary values.
  • Explain why one sequence of bits can mean different things in different contexts.
  • Describe overflow and approximation as consequences of digital representation.

Build the model

bit

Smallest digital unit

A bit is either 0 or 1. A byte contains eight bits.

place value

Base 2

From right to left, place values are 1, 2, 4, 8, 16, and so on. Each value is multiplied by 0 or 1.

abstraction

Bits are not only numbers

Groups of bits can represent numbers, characters, colors, and more. Interpretation depends on format and context.

Worked example

101101₂ = 1×32 + 0×16 + 1×8 + 1×4 + 0×2 + 1×1 = 45₁₀
13₁₀ = 8 + 4 + 1 = 1101₂

Number positions from zero at the right. List the place values first, then choose the values that add to the target number.

Analog, digital, and limits

Pitch, volume, and position can vary continuously. A computer samples them at intervals and stores a finite representation. This useful abstraction can introduce approximation. A fixed number of bits can also limit integer range and cause overflow.

Original practice

  1. Convert 100110₂ to decimal and identify each place value containing a 1.
  2. Convert decimal 26 to binary.
  3. Why might two devices display the same bits as a color and as a character?
  4. What rapid change might be missed if a sensor samples only twice each second?

Exit ticket

Why does “all computer data are bits” not mean that all data are simply numbers made of zeros and ones?
