0. Decide what the first version must do

A command-line interface (CLI) uses the terminal for input and output. The diary list is our operation center: display it immediately at startup, then show the menu. After each operation, return to the refreshed list and menu.

ChoiceInputProgram actionOutput
1 SearchA word, then an optional result numberFilter entries; view the chosen matchMatches or “no match”
2 AddOne line of fictional textReject blank text; save a recordA saved message and refreshed list
3 DeleteAn entry number and confirmationRemove only the chosen recordA deletion message and refreshed list
4 View/editAn entry number, then an actionShow the entry; optionally edit or delete itThe entry and any saved change
5 QuitNo extra inputStop the menu loopA goodbye message

Flow: load entries → display the list (or an empty-list message) → choose an operation → return to the list. Quit ends the loop. We will build this in small steps: first memory, then files, search, and finally editing and deletion. List display is automatic, so it needs no menu choice.

1. Create an empty Python file

Make a folder for this exercise and create a blank file named diary.py in it. Use a local terminal with Python 3.9 or newer. From that folder, run:

python3 diary.py

An empty file exits without printing anything. That is your starting point. On Windows, use py diary.py if python3 is unavailable.

2. Build the menu loop

Type this into diary.py. Each if branch is a placeholder for one future feature.

entries = []
while True:
    print("\nYour diary entries:")
    print("No entries yet. Add one to begin.")
    print("\nCLI Diary: 1 Search | 2 Add | 3 Delete | 4 View/edit | 5 Quit")
    choice = input("Choose 1–5: ").strip()
    if choice == "1":
        print("Search comes later.")
    elif choice == "2":
        print("Add comes next.")
    elif choice == "3":
        print("Delete comes later.")
    elif choice == "4":
        print("View/edit comes later.")
    elif choice == "5":
        print("Goodbye.")
        break
    else:
        print("Choose 1, 2, 3, 4, or 5.")

input() waits for the user. strip() removes surrounding spaces. while True keeps showing the list and menu, and break stops it when the user chooses Quit.

Checkpoint A

Run the file. Check that the empty list appears before the menu. Try 2, an invalid choice, and 5. Explain why the menu reappears after the first two choices but not after Quit.

3. Add and list entries in memory

Keep entries = [] above the loop. Inside the loop, replace the empty-list placeholder with this display block, before printing the menu:

if entries:
    for number, text in enumerate(entries, start=1):
        print(f"{number}. {text}")
else:
    print("No entries yet. Add one to begin.")

Replace only the Add branch; keep the other branches:

elif choice == "2":
    text = input("Write one fictional entry (Enter to cancel): ").strip()
    if text:
        entries.append(text)
        print("Entry added.")
    else:
        print("Nothing was added.")

The list is the first data structure. append() adds one item; the for loop displays every item. Add two fictional sentences. Both appear automatically before the next menu. Then quit and restart: the list is empty because it existed only in memory.

Checkpoint B

Predict the output before testing: What happens if you choose Add and press Enter without typing text? What happens to the two entries after a restart?

4. Give each entry a time and save it to a file

Now one entry should be a dictionary with two fields: text is the content, and created_at describes when that content was added. Put these imports, paths, and helper functions above the menu loop:

import json
from datetime import datetime
from pathlib import Path

DATA_DIR = Path.home() / ".csp-diary"
DATA_FILE = DATA_DIR / "entries.jsonl"

def save_entry(text):
    entry = {
        "created_at": datetime.now().astimezone().isoformat(timespec="minutes"),
        "text": text,
    }
    DATA_DIR.mkdir(parents=True, exist_ok=True)
    with DATA_FILE.open("a", encoding="utf-8") as file:
        file.write(json.dumps(entry, ensure_ascii=False) + "\n")

def load_entries():
    if not DATA_FILE.exists():
        return []
    with DATA_FILE.open("r", encoding="utf-8") as file:
        return [json.loads(line) for line in file if line.strip()]

Remove entries = []. In Add, replace entries.append(text) with save_entry(text). At the beginning of the loop, replace the heading and memory-list display with:

entries = load_entries()
print("\nYour diary entries:")
if entries:
    for number, entry in enumerate(entries, start=1):
        print(f'{number}. [{entry["created_at"]}] {entry["text"]}')
else:
    print("No entries yet. Add one to begin.")

Path.home() keeps the data outside this website and your practice folder. File mode "a" appends a line without replacing older lines. json.dumps() turns a dictionary into text; json.loads() turns that text back into a dictionary. One JSON object per line is called JSON Lines.

{"created_at":"2026-09-29T10:30+08:00","text":"Today I compared two data sets."}

The time stamp is metadata: it describes the diary entry. It is useful for organizing entries, but it is not the entry's text.

Checkpoint C

Add a fictional entry, quit, restart, and inspect the startup list. The entry should still appear. Find the exact data path by reading DATA_DIR and DATA_FILE; do not copy the saved file into the website folder.

5. Add a case-insensitive search

Replace the Search placeholder with this branch. It uses the entries loaded at the start of this loop, keeps the positions of matching records, and displays them. Selecting a result comes in the next step.

if choice == "1":
    term = input("Search word (Enter to cancel): ").strip().casefold()
    if not term:
        print("Search cancelled.")
    else:
        indices = [
            index for index, entry in enumerate(entries)
            if term in entry["text"].casefold()
        ]
        if indices:
            for number, index in enumerate(indices, start=1):
                entry = entries[index]
                print(f'{number}. [{entry["created_at"]}] {entry["text"]}')
        else:
            print("No matching entries.")

casefold() makes ordinary letter-case differences irrelevant to this search. The list comprehension is a filter (a query): it builds a list of positions whose entries meet the condition. Filtering changes which entries are shown; sorting changes their order. This search keeps the original saved order and does not sort or change the saved data.

Checkpoint D

Save an entry containing Python. Search for python, then for a word that is absent, then press Enter at the search prompt. Explain all three results.

6. Use procedures, then complete CRUD

Before adding more behavior, give repeated tasks names: show_entries(entries, indices=None, empty_message=...) displays a full list or selected positions; add_entry() adds text; search_entries(entries) searches the current list. Put the single menu loop in main() and call it at the bottom. Use return to finish an operation; never call main() from another menu or from itself.

CRUD means Create (Add), Read (List, Search, View), Update (Edit), and Delete. Add already appends with file mode "a". Editing or deleting requires writing the whole remaining list with mode "w", which replaces the file contents. Load the list first, change only the selected entry, then write all remaining records in the same JSON Lines format:

def write_entries(entries):
    DATA_DIR.mkdir(parents=True, exist_ok=True)
    with DATA_FILE.open("w", encoding="utf-8") as file:
        for entry in entries:
            file.write(json.dumps(entry, ensure_ascii=False) + "\n")

Display numbers start at 1; Python positions start at 0. A search adds another difference: its first result might be the third saved entry. Use indices as a mapping. For example, [2, 4] means result 1 is entries[2] and result 2 is entries[4]. For the full list, use list(range(len(entries))). Validate input before indexing:

def choose_entry(indices):
    if not indices:
        return None
    choice = input("Entry number (Enter to cancel): ").strip()
    if not choice:
        print("Cancelled.")
        return None
    try:
        number = int(choice)
    except ValueError:
        print("Choose a displayed entry number.")
        return None
    if not 1 <= number <= len(indices):
        print("Choose a displayed entry number.")
        return None
    return indices[number - 1]

try/except ValueError handles text that cannot become an integer. The range check rejects zero, negative numbers, and numbers outside the displayed list. None means no selection; test index is not None, since position 0 is valid.

After displaying the matches with show_entries(entries, indices, "No matching entries."), add this selection step to search_entries(entries):

index = choose_entry(indices)
if index is not None:
    view_entry(entries, index)

Use these procedures for editing and deleting. Editing keeps the creation time and any other existing fields. A blank replacement cancels. Deletion previews the chosen entry and requires y; any other reply cancels.

def edit_entry(entries, index):
    text = input("Replacement text (Enter to cancel): ").strip()
    if not text:
        print("Nothing was changed.")
        return
    entries[index]["text"] = text
    write_entries(entries)
    print("Entry updated locally.")
def delete_entry(entries, index):
    entry = entries[index]
    print(f'Delete [{entry["created_at"]}] {entry["text"]}')
    confirm = input("Type y to delete (Enter to cancel): ").strip().casefold()
    if confirm != "y":
        print("Nothing was deleted.")
        return
    del entries[index]
    write_entries(entries)
    print("Entry deleted locally.")

In view_entry(entries, index), print the chosen entry, then offer 1 Edit, 2 Delete, or Enter to return. In main(), Search calls search_entries(entries), Add calls add_entry(), and Delete and View/edit use choose_entry(list(range(len(entries)))) before calling the matching procedure. An empty list makes no selection. After a procedure returns, the loop reloads and displays the saved list, so old search numbers are not reused.

先了解考试流程

  1. 考前开发：学校提供至少 9 小时课堂时间完成 Create。程序需要真实使用输入、输出、管理复杂度的列表，以及带有效参数的学生自编过程；选定过程内部要包含顺序、选择和迭代，并在程序中被调用。
  2. 考前提交：在 AP Digital Portfolio 分别将完整代码 PDF、运行视频和 Personalized Project Reference（PPR）提交为 final。视频须展示输入、功能、输出，最长 1 分钟、最大 30 MB，不含身份信息或旁白；视频与 PPR 必须独立完成。完整代码需保留外部代码/AI 来源说明；PPR 只能放规定的代码截图，不能含注释、课程笔记或预写答案。
  3. 考试当天：在 Bluebook 完成 Section I：70 道选择题、120 分钟，占 70%；Section II：2 道书面题、共 4 个提示、60 分钟。Create 与书面回答合计占 30%。答书面题时可使用已按时提交为 final 的本人 PPR，不能把本教学页当作考场参考。
  4. 现场按题回答：四类是 WR1（设计、功能和目的）、WR2(a)（算法）、WR2(b)（错误与测试）、WR2(c)（数据与过程抽象）。每年问法会变；先圈出题目要求，再用自己的代码、具体数据和因果解释回应。

先选对程序证据，再写回答

就代码结构而言，现有 show_entries(entries, indices=None, empty_message=...) 是清晰的过程分析对象：entries 提供记录，indices 决定显示哪些位置及顺序，empty_message 决定空结果提示。过程先准备位置列表，再检查空列表（选择），随后遍历位置（迭代），取出时间和正文并打印（顺序）。main() 中的 show_entries(entries) 是一次调用；搜索使用 show_entries(entries, indices, "No matching entries.")。现在的 search_entries(entries) 也有参数，不能沿用旧版“搜索过程没有参数”的描述。这些结构分析不代表参考代码满足学生原创要求。

练习列表证据时，可沿着 search_entries(entries) 中的 indices = [...]（把匹配记录的原位置存入列表），追踪到 show_entries 内对这些位置的遍历，以及 choose_entry(indices) 中的 indices[number - 1]。例如 [2, 4] 把显示编号 1、2 映射回原列表位置 2、4；编辑和删除都使用返回的原位置。entries 是字典记录列表，indices 是整数位置列表，文件 entries.jsonl 本身不是 Python 列表。正式 PPR 应从自己的程序中独立选择对应片段。

WR1 · Program Design, Function, and Purpose

练习方向：程序服务谁、解决什么问题？说明一个输入如何产生输出。回答要区分目的（为什么需要）与功能（程序做什么）。

英文示例：My program helps a learner save and retrieve short practice notes. It displays the saved notes before the menu and refreshes the list after each operation. The user enters a note through the terminal, and the program stores its text with a timestamp in a local file. When the user enters a search word, the program displays matching notes. This helps the learner find earlier notes without reading every saved entry manually.

代码依据：input() 接收正文/关键词/编号；save_entry(text) 写文件；搜索用 casefold() 忽略大小写；show_entries 输出编号、时间、正文。若题目只问某一项，就聚焦该项，不必把所有功能重写一遍。

WR2(a) · Algorithm Development

练习方向：解释 show_entries(entries) 的算法，并追踪迭代次数。假定传入两条有效记录，正文依次为 Learn Python 和 Read a book。

英文示例：When indices is omitted, the procedure builds the positions of all entries. It checks whether this position list is empty; if so, it prints the empty message and returns. Otherwise, the for loop visits each selected position and retrieves its entry. With two entries, the loop body executes twice. On each iteration, it prints the entry number, timestamp, and text, in the original list order.

说明原因：省略 indices 时，过程生成全部位置，循环体执行 len(entries) 次；传入筛选位置时，执行 len(indices) 次。位置列表为空就提前返回，循环执行 0 次。参数换成另一组记录或位置，输出也会改变。若问无限循环，须针对自己的循环解释：当前 for 遍历有限且未被追加的列表会结束；假设把它改成没有退出条件的 while True，才会无限重复。不要把菜单中持续等待用户输入与这个列表循环混为一谈。

WR2(b) · Errors and Testing

练习方向：给出测试输入、预期结果以及它验证的行为。测试前提：使用一个只含下面两条虚构记录的练习数据文件。

英文示例：With the two saved notes “Learn Python” and “Read a book”, I would search for “python”. I expect only the first note in the search results because both the search term and each note are case-folded before the substring comparison. This checks that capitalization does not prevent a match.

如果题目问错误：把 entry["text"] 误改为 entry["body"]，在显示现有的非空记录时会产生 KeyError，因为记录只有 created_at 和 text 键；恢复正确键名可修复。空列表会提前返回，不能触发这个错误。若题目要求“过程的测试调用”，应直接给 show_entries 的具体参数及结果，而不只写菜单操作。

WR2(c) · Data and Procedural Abstraction

练习方向：指出具体列表、元素内容，以及它如何管理复杂度；再说明参数化过程如何减少重复。

英文示例：The entries list stores diary records containing a timestamp and text. The indices list stores the original positions of matching records. A single loop can display any number of results, and indices maps each result number back to the correct record for viewing, editing, or deletion. Without this list, storing a separate position and selection branch for each match would require code changes as the number of matches grows. The show_entries procedure lets the operation-center list and Search share the same display logic; a change to the output format can be made in one place.

如果题目要求新算法：例如统计正文恰好等于目标值的记录：先把计数设为 0；逐条遍历列表；比较当前记录的 text 与目标值，相等就加 1；遍历结束后返回计数。若题目提供比较过程，就按其规格调用；不能把“正文完全相等”偷换成原程序的“包含关键词”。这是一种算法描述练习，不是现有程序已实现的功能。
