Data: representation, compression, insight, and programs

Four classroom handouts connect data representation to evidence-based insights. A separate Python practice lab turns those ideas into a local command-line program.

Learning path: understand bits and binary first, compare compression tradeoffs, examine the limits of data claims, then process synthetic content data with Python.
